# Inventory Management System

## Description

Inventory Management System is a console-based Java application designed to manage products and stock quantities.

It provides basic CRUD operations for managing inventory.

## Features

- Add products
- View products
- Search products
- Update product quantity
- Delete products
- Product ID management
- Console-based interface

## Technologies Used

- Java
- OOP
- ArrayList
- Collections
- Scanner

## CRUD Operations

- Create - Add Product
- Read - View Product
- Update - Update Quantity
- Delete - Delete Product
